How to get your FREE Firebase Database URL in 2 mins:
  1. Open console.firebase.google.com (Free Google Account).
  2. Click Add project (e.g. disha-academy).
  3. In left menu, click Build → Realtime Database → Create Database (Select Test mode).
  4. Copy your database URL (e.g. https://disha-academy-default-rtdb.firebaseio.com) and paste it below!
Can also be set in Render Dashboard → Environment as FIREBASE_DATABASE_URL.
